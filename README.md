# One Stream

A movie and TV streaming app for Android phones and Android TV.

## Download

| Device | Download |
|---|---|
| Android phone (64-bit) | [**OneStream-phone.apk**](https://github.com/kirtanya/one-stream/releases/latest/download/OneStream-phone.apk) |
| Android TV | [**OneStream-tv.apk**](https://github.com/kirtanya/one-stream/releases/latest/download/OneStream-tv.apk) |

These links always point to the newest version. Older versions and release notes: [Releases](https://github.com/kirtanya/one-stream/releases).

## Install

1. Download the APK on the device (or copy it over).
2. Open it. Android may ask you to allow installs from that app (your browser or Files): allow it once.
3. If Play Protect suggests a scan, tap **Scan app**. This is normal for apps installed outside the Play Store.
